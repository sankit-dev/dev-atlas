# Design Principles & Patterns

Once you understand classes, relationships, and OOP principles, the next step is designing code that stays maintainable as it grows.

This area has two parts:

- **Design principles**: rules of thumb for structuring code.
- **Design patterns**: common reusable solutions to common design problems.
