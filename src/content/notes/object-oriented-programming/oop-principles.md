# OOP Principles

OOP is not only about creating classes.

The useful part is learning how to organize behavior, protect data, hide complexity, and swap implementations safely.

The main principles are:

- Encapsulation
- Abstraction
- Polymorphism
- Inheritance

---

# What comes under OOP Principles?

```plain text
OOP Principles
├── Encapsulation
├── Abstraction
├── Polymorphism
└── Inheritance
```

Learn them in this order. Encapsulation and abstraction explain how objects hide detail. Polymorphism and inheritance explain how behavior can vary across types.
