# MongoDB Coding Exercises

MongoDB exercises test whether you can model data and query it efficiently.

## Exercises included

- User/post/comment schema.
- CRUD with Mongoose.
- Search and pagination.
- Aggregation reports.
- Order placement with transaction.

For every exercise, mention indexes and explain why you embedded or referenced data.
