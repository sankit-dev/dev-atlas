# MongoDB Must Know

This branch covers the MongoDB topics needed for MERN apps.

## Topics here

- What MongoDB is.
- Documents and collections.
- MongoDB vs SQL.
- CRUD operations.
- Query and update operators.
- Schema design.
- Embedding vs referencing.
- Indexes.
- Aggregation pipeline.
- Mongoose schema and model.
- Mongoose validation.
- Population.

## Practice rule

For every schema, write the read queries first. MongoDB design should follow access patterns.
