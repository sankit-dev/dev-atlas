Machine Learning, Deep Learning, and Generative AI are related, but they are not the same thing.

## The hierarchy

AI is the broad field. Machine Learning is one way to build AI systems. Deep Learning is one way to build Machine Learning systems. Generative AI is a family of models that create new content.

| Term | Meaning |
| --- | --- |
| Artificial Intelligence | Systems that perform tasks that normally need human intelligence |
| Machine Learning | Systems that learn patterns from data |
| Deep Learning | ML using neural networks with many layers |
| Generative AI | Models that generate text, images, code, audio, or other outputs |

## Machine Learning

Machine Learning uses data to learn patterns instead of relying only on hand-written rules.

Common examples:

- Spam detection.
- Fraud detection.
- Product recommendations.
- Demand prediction.
- Search ranking.

The model is trained on examples, then used to make predictions on new input.

## Deep Learning

Deep Learning uses neural networks with many layers. These models are powerful for unstructured data like text, images, speech, and video.

Deep Learning is useful when the pattern is hard to express with normal rules.

Examples:

- Image recognition.
- Speech-to-text.
- Language translation.
- Large language models.

## Generative AI

Generative AI creates new content instead of only classifying or predicting a label.

Examples:

- Answering questions.
- Summarizing documents.
- Writing code.
- Creating images.
- Drafting emails.

## Backend developer view

For backend work, you usually do not train foundation models yourself. You call a model API, pass input, control behavior with prompts and parameters, store context, and validate output.

## Quick revision

- AI is the broad umbrella.
- ML learns from data.
- Deep Learning uses multi-layer neural networks.
- Generative AI creates new content.
- Backend developers mostly integrate models into reliable systems.
