# Express.js Must Know

This branch covers the concepts needed for real API development.

## Topics here

- What Express is.
- Routing.
- Params, query, and body.
- Middleware.
- Controllers and services.
- REST API design.
- Request validation.
- Error handling middleware.
- Authentication and JWT.
- Authorization.
- CORS.
- Pagination, filtering, and sorting.

## Practice rule

Build one CRUD API manually. Then add validation, error handling, auth, and pagination one by one.
