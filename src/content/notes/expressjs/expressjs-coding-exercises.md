# Express.js Coding Exercises

Express coding rounds usually ask for a small API with clean behavior.

## Exercises included

- CRUD API.
- JWT auth API.
- Role-based authorization API.
- Pagination and search API.
- URL shortener API.

For every API, define routes, request body, response shape, error cases, and validation rules before coding.
