# MERN Projects

Projects prove that you can connect the stack.

Do not build only UI. Do not build only APIs. A MERN project should include frontend, backend, database, validation, auth where needed, and deployment thinking.

## Projects included

- Todo app with auth.
- Blog app with comments.
- Notes app with search.
- URL shortener.
- Basic e-commerce app.

## What every project should show

- Clear API contract.
- Good folder structure.
- Validation on backend.
- Loading, error, and empty UI states.
- Protected routes if auth exists.
- MongoDB schema design.
- Environment variables.
- README with setup instructions.
