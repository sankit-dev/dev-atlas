# React Coding Exercises

React coding rounds usually test practical UI building.

They care about:

- component breakdown,
- state management,
- API integration,
- conditional rendering,
- form handling,
- routing,
- edge cases.

## How to solve React exercises

Before coding, write:

- components needed,
- data shape,
- state variables,
- events,
- API contract if needed,
- loading/error/empty states.

Then build small and improve.
