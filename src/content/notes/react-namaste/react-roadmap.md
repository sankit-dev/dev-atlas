# React Roadmap

React is the UI layer of the MERN stack.

It helps you build user interfaces as small reusable components.

## Study order

```text
React element -> JSX -> Components -> Props -> State -> Hooks -> Data fetching -> Routing -> State sharing -> Optimization
```

This order matters.

If components and props are unclear, hooks feel confusing.

If state is unclear, data fetching and forms become messy.

If routing is unclear, MERN apps feel disconnected from backend APIs.

## Branches in this track

- **React Must Know**: the main path for building React apps.
- **React Good to Know**: class components, optimization, and styling choices.
- **React Coding Exercises**: machine-coding style practice.

## Interview angle

If asked what React is, say:

> React is a JavaScript library for building user interfaces using reusable components. It updates the UI efficiently when state changes and helps structure frontend applications around components, props, state, and hooks.
