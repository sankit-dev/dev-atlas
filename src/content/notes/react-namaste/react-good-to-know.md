# React Good to Know

These topics are useful after you understand components, props, state, hooks, data fetching, and routing.

## Topics here

- Class components and lifecycle methods.
- Custom hooks and optimization.
- Lazy loading and code splitting.
- Styling choices in React.
- Tailwind and component libraries.

## Practical view

Good-to-know does not mean optional forever.

It means:

> Learn the core React path first, then use these topics to make apps cleaner, faster, and more maintainable.
