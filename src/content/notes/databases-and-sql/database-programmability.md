# Database Programmability

Database programmability is about putting reusable logic inside or near the database.

This can help when the database should expose a simplified view of data or run logic close to the stored records.

---

# What comes under Database Programmability?

```plain text
Database Programmability
├── Views
└── Stored Procedures & Triggers
```

Use these carefully. They can make some database workflows cleaner, but too much hidden database logic can also make systems harder to reason about.
