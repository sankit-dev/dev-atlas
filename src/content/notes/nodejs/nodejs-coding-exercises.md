# Node.js Coding Exercises

Node.js exercises usually test practical backend behavior, not syntax trivia.

## Exercises included

- HTTP server without Express.
- CLI tool.
- File upload with streams.
- Custom EventEmitter.
- In-memory rate limiter.

For every exercise, explain what the runtime is doing: reading input, handling IO, storing state, streaming data, or limiting repeated actions.
