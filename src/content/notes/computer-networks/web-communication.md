# Web Communication

Web communication is about how browsers, mobile apps, frontend apps, and backend servers talk to each other.

Most backend work happens here:

- A client sends a request.
- A server processes it.
- The server sends a response.
- Security, auth, cookies, CORS, and real-time communication sit around this flow.

---

# What comes under Web Communication?

```plain text
Web Communication
├── HTTP
├── HTTPS
├── REST API
├── WebSockets
├── CORS
├── Cookies vs Sessions vs JWT
└── Authentication vs Authorization
```

Start with HTTP, because HTTPS, REST, cookies, CORS, and WebSockets all make more sense after the request-response model is clear.
