# Network Infrastructure

Network infrastructure is the set of components and concepts that help traffic reach the right application reliably and efficiently.

It includes:

- Distributing traffic across servers.
- Proxying requests to backend services.
- Serving content from edge locations.
- Identifying services using ports.
- Writing programs that communicate over sockets.
