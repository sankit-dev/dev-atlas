# Transport Layer

The Transport Layer is responsible for communication between applications running on different machines.

It answers:

- Should the data be delivered reliably?
- Should missing data be resent?
- Should data arrive in order?
- Which application on the destination machine should receive it?

The two main protocols are:

- **TCP**
- **UDP**
