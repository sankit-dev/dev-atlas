# JavaScript Roadmap

JavaScript is the language behind both sides of the MERN stack.

React uses JavaScript in the browser. Node.js uses JavaScript on the server. Express is built on Node.js. MongoDB is often used through JavaScript drivers or Mongoose.

So before going deep into MERN, JavaScript needs a proper base.

## How to study this track

Do not study JavaScript as random syntax.

Study it in three layers:

1. **Must Know**: concepts you need for daily React, Node, Express, and interviews.
2. **Good to Know**: useful ideas that make you stronger but can come after the core path.
3. **Coding Exercises**: problems commonly asked in frontend and MERN coding rounds.

## What matters most

For MERN, the most important JavaScript areas are:

- how code executes,
- how scope and closures work,
- how `this` works,
- how objects inherit through prototypes,
- how arrays and objects are transformed,
- how async code works,
- how promises and `async/await` behave,
- how to write common utilities from scratch.

## Simple learning order

```text
Execution -> Scope -> Closures -> this -> Prototypes -> Arrays/Objects -> Async -> Exercises
```

This order is intentional.

If closures are unclear, React hooks feel magical.

If event loop is unclear, Node.js async behavior feels random.

If prototypes are unclear, JavaScript objects and classes feel confusing.

## Interview answer

For MERN, JavaScript is the foundation language. I would first focus on execution context, call stack, scope, hoisting, closures, `this`, prototypes, arrays/objects, event loop, promises, async/await, modules, and error handling. After that, I would practice common coding exercises like polyfills, debounce, throttle, deep clone, promise utilities, event emitter, and LRU cache.
