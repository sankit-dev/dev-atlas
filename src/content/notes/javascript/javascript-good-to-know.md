# JavaScript Good to Know

This branch is for concepts that are useful but should not block your first MERN path.

Study these after the must-know concepts feel comfortable.

## Topics here

- Classes in JavaScript.
- Shallow copy vs deep copy.
- Memory leaks.
- Currying and memoization.

These show up in interviews and real apps, but they make more sense after you understand functions, objects, scope, and references.

## Practical view

Good-to-know does not mean unimportant.

It means:

> Learn it after the core path, not before it.
